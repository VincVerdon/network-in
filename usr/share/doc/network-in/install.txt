Network-In! installation notes
Version 
-------------------------------

English :
---------
It's easy to install Network-In! software on GNU/Linux Debian.
Root account has to do :
Install the software with apt install command :
	apt install network-in_2.xx_amd64.deb
apt is better than dpkg because it installs automatically packets that are needed.

Français :
----------
Il est facile d'installer le logiciel Network-In! sur une GNU/Linux Debian.
Le compte root doit faire les choses suivantes :
Installer le logiciel avec la commande apt install :
	apt install network-in_2.xx_amd64.deb
apt est mieux que dpkg car elle installe automatiquement les paquets qui sont nécessaires.
