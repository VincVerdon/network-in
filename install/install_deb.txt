Installation Network-In! à partir du paquet deb
------------------------------------------------
-------------------------------------------------


Sous Debian :
--------------
Ouvrir un terminal
Devenir admin (root) : su - (saisir le mot de passe de root)
Installer : apt install <dossier du paquet deb>/network-in-<version>.deb
Exemple : apt install /home/vincent/Téléchargements/network-in-2.0-beta13.deb


Sous Ubuntu
------------
Ouvrir un terminal
Installer : sudo apt install <dossier du paquet deb>/network-in-<version>.deb     (saisir le mot de passe de l'utilisatuer)
Exemple : sudo apt install /home/vincent/Téléchargements/network-in-2.0-beta13.deb
